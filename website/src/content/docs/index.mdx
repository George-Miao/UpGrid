## Monitoring without a control-plane dependency

Every UpGrid Node runs the API, WebUI, scheduler, probe worker, notification worker, and a copy of the Raft state. Add a service once and the Cluster coordinates who checks it.

<CardGrid stagger>
	<Card title="One interface on every Node" icon="document">
		Use the same authenticated API and WebUI on any healthy member. Followers forward mutations to the leader.
	</Card>
	<Card title="Distributed evaluations" icon="rocket">
		The leader assigns HTTP and HTTPS polls across voting Nodes and commits one result for each interval.
	</Card>
	<Card title="Useful alerts" icon="open-book">
		Notify Telegram chats, email recipients, or webhooks when a service or Cluster Node changes availability.
	</Card>
	<Card title="Elegant WebUI" icon="setting">
		Configure Targets, inspect history, manage alerts, and operate the Cluster from a responsive dashboard.
	</Card>

## Begin with one Node

Build UpGrid, start a Node, and open its first-run setup page. You can create a single-Node Cluster immediately and invite more Nodes later.
