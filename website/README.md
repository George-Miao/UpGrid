# UpGrid documentation website

The static documentation site for [UpGrid](https://upgrid.rs), built with Astro Starlight.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Write pages in `src/content/docs/`, update navigation in `astro.config.mjs`, and run `pnpm build` before committing. The production build is written to `dist/` and is not checked in.
